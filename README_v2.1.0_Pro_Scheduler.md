# NOVRIA AI Music Studio v2.1.0 — Pro Scheduler

## 专业任务调度
自动流水线现在增加：
- 高 / 普通 / 低优先级
- 按优先级重排
- 多 GPU 列表与 GPU 选择
- GPU 显存保护
- GPU 温度保护
- 夜间批处理时间窗
- 失败指数退避重试

## GPU 保护
默认：
- 显存占用达到 85%：暂缓启动下一阶段
- GPU 达到 82°C：等待降温

通过 nvidia-smi 可获得温度/显存时优先使用真实数据。
如果不可用，仍保留 PyTorch CUDA 检测。

## 夜间批处理
例如设置：
23:00 → 07:00

开启后，白天不会启动新的自动任务。
正在执行的单个安全阶段不会被粗暴终止。

## 失败退避
流水线阶段失败后：
第一次等待约 15 秒
第二次等待约 30 秒
最多自动重试 2 次

避免网络、显存和临时资源问题导致连续疯狂重试。

## Musical Intelligence 接入流水线
v2.0 的流水线编配比较基础。
v2.1 加入段落角色思想：
- Intro 减配
- Verse 保持空间
- Chorus 提升吉他/Bass/Drums
- Bridge 留白
- Outro 收束
- Chorus 末尾自动 Fill

这样批量自动生成的 MIDI 不再每个小节完全相同。
