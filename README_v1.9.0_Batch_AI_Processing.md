# NOVRIA AI Music Studio v1.9.0 — Batch AI Processing

## 批量六轨真正执行
v1.8.0 只有任务队列。
v1.9.0 会逐首调用已经稳定的 Demucs 六轨 SeparationWorker 真正处理队列。

## 支持
- 开始批处理
- 暂停 / 继续
- 失败自动重试 1 次
- 手动“重试失败”
- 当前歌曲进度
- 总进度
- 每首歌状态 / 设备 / 失败原因
- 队列持久化，软件重开后仍可读取

## 暂停策略
为了避免强行中断 GPU 推理导致模型/显存异常，
“暂停”会让当前歌曲安全处理完，再停止启动下一首。

## 运算模式
- 自动 GPU/CPU
- 优先 NVIDIA GPU
- 仅 CPU

实际单曲 Worker 仍以 PyTorch CUDA 可用性作为最终设备能力判断。

## 后处理
六轨完成后可自动：
- BPM / 调性分析
- 标记为“待出谱”

后面可以继续扩展为：
六轨 → 分析 → 和弦/谱面 → 智能改编 → 渲染
的一条自动流水线。
