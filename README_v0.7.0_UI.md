# NOVRIA AI Music Studio v0.7.0 UI Refresh

## 本版本重点
- 全新 NOVRIA Neon Dark 专业音乐工作站主题
- 重新设计应用图标，提供 PNG / ICO
- 左侧品牌区 + 图标导航
- 六大模块统一图标风格
- 主按钮、危险按钮、成功按钮重新分级
- 统一 Microsoft YaHei UI / Segoe UI 字体体系
- 优化圆角、边框、Hover、Pressed、Disabled 状态
- 优化 Slider / ProgressBar / ComboBox / Table / Checkbox
- 六轨使用不同强调色，识别更快
- 增大主窗口并优化页面留白
- 内置两张 UI 视觉参考图，方便继续迭代

## 视觉方向
深色舞台 / 专业 DAW / 紫蓝霓虹 / 低干扰 / 高对比 / 现场演出友好。

## 重要
本版本不改变 v0.6.0 已经实现的六轨、Setlist、MIDI、耳返节拍器等核心逻辑，
主要升级视觉层，降低因界面重构导致核心功能回归的风险。
