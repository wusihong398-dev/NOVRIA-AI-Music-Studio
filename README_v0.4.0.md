# NOVRIA AI Music Studio v0.4.0

这是在 v0.3.2 测试稳定基础上继续完善的 Windows 音乐工作站版本。

## v0.4.0 新增
- 波形时间轴
- 点击波形快速定位
- 播放头实时移动
- BPM 自动分析
- 调性参考分析
- 段落 Marker：前奏 / 主歌 / 副歌 / 间奏 / 尾奏等
- Marker 写入 NOVRIA 工程文件
- 模型目录管理入口
- 项目 / 导出 / 模型目录标准化
- 保留模型下载进度与六轨分离真实进度
- 保留六轨真实 Mute / Solo / 音量
- 保留吉他 / 钢琴 / 鼓 / 贝斯现场演出预设
- 保留 WAV 混音导出

## 测试重点
1. 导入歌曲并完成六轨分离。
2. 检查波形是否出现。
3. 点击波形不同位置，检查播放是否跳转。
4. 点击“分析 BPM / 调性”。
5. 在前奏、主歌、副歌等位置添加 Marker。
6. 保存工程，确认 Marker 和分析结果被写入工程。
7. 进入现场演出模式测试关闭 Guitar / Piano。
