# NOVRIA AI Music Studio v1.6.0 — A/B Pro Compare

## 新增：A/B 自动响度匹配
比较 A/B 时先把两版的整体 RMS 电平匹配到较低的一版，降低“更响的一版听起来更好”的干扰。

注意：当前使用的是节目 RMS 匹配，不宣称为广播级 LUFS 校准。

## 瞬时 A/B 切换
- 切到 A
- 切到 B
- 两个 WAV 保持同一个播放位置
- 使用 512-frame 音频块，尽可能降低切换延迟
- 可以配合“只循环当前段落”

## 双波形
A/B WAV 渲染完成后分别显示波形，方便观察动态和段落差异。

## A/B 差异分析
响度匹配后计算：
- 波形差异强度
- 波形相关度
- A/B RMS 电平

用来辅助判断两个编配到底改变了多少。

## 历史一键恢复
在历史表格选择一条记录，点击“恢复所选历史”，即可恢复：
- 人工段落微调
- A/B 配置
- 当前采用版本

Undo / Redo 仍然保留。

## 推荐流程
生成自动编配
→ 微调 A/B
→ 渲染 A/B
→ 自动响度匹配
→ 循环副歌
→ 瞬时切 A/B
→ 查看差异
→ 采用版本
→ 保存历史。
