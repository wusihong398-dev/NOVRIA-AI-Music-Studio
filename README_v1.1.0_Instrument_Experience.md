# NOVRIA AI Music Studio v1.1.0 — Instrument Experience

这一版重点不是继续堆按钮，而是让吉他手、贝斯手、鼓手、键盘手更容易使用。

## 一键乐手模式
选择：
- 吉他手
- 贝斯手
- 鼓手
- 键盘手

软件会：
1. 自动关闭本人现场演奏的对应 Stem。
2. 自动切换到对应乐手设置。
3. 自动切换对应演出谱面。
4. 保存该歌曲的乐手参数。

## 吉他
- 简化 / 标准 / 丰富 / 专业
- 标准调弦 / Drop D / 降半音
- Capo 0-12
- 扫弦 / 分解 / Power Chord / Fingerstyle 参考
- 演奏密度

## Bass
- 4弦 / 5弦
- 根音、根音+五度、八度、Walking参考
- 音符密度
- 音区

## Drums
- Groove
- Hi-Hat / Ride
- Fill 密度
- 力度
- 段落/小节实时提示

## Piano / Keyboard
- 左手根音 / 五度 / 八度 / 分解
- 右手三和弦 / 转位 / Pad / Rhodes
- Sustain
- 织体密度

## 排练助手
- 段落选择
- 一键跳到所选段落
- 循环当前段落
- 4 拍 Count-in
- 70% / 85% / 100% 练习速度预设入口
- 实时显示当前段落、小节、和弦

注意：70%/85% 目前作为练习预设参数保存，真正高质量实时变速 DSP 仍保持与核心播放器分离，后续单独接入，避免影响现场稳定性。
