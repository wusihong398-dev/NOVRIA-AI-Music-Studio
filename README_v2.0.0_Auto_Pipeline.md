# NOVRIA AI Music Studio v2.0.0 — Auto Pipeline

## 自动生产流水线
v2.0.0 把前面各版本的独立模块串成一个统一任务流：

导入 / 音乐库
→ 六轨分离
→ BPM / 调性
→ 和弦 / 段落
→ Lead Sheet
→ 新 MIDI 编配
→ SoundFont 渲染
→ WAV / MP3
→ 更新音乐库

## 每首歌有独立阶段状态
音乐库内可看到每个任务处于：
- 六轨
- 分析
- 和弦
- 乐谱
- 改编
- 渲染
- 入库

任务状态写入：
`library/auto_pipeline_jobs.json`

软件重启后可以恢复任务信息。

## 暂停 / 继续
流水线采用“安全阶段边界暂停”：
当前 AI 阶段处理完以后停止进入下一阶段，
避免在 GPU 推理中间强行杀进程。

## 失败续跑
失败的歌曲会保存失败阶段。
点击“继续失败任务”后，只重新处理未完成/失败阶段，不需要从导入开始。

## 本地 / 云端执行器
v2.0.0 提供：
- 本地执行器：已经工作
- 云端执行器：接口已经预留，但当前测试版尚未绑定服务器 API

未来部署 NOVRIA 云端 GPU 后，客户端可以保持相同任务结构，只切换执行器。

## 渲染要求
流水线自动渲染需要先在“AI 改编 / 乐谱”页面选择用户有权使用的 SoundFont。
MP3 输出还需要 FFmpeg。

## 当前自动编配说明
流水线使用规则化的新 MIDI 伴奏生成，不直接把原 MP3 Stem 作为最终改编伴奏。
复杂人工微调、A/B 编配仍可在单曲工作区继续完成。
