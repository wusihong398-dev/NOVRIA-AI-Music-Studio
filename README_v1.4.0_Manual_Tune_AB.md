# NOVRIA AI Music Studio v1.4.0 — Manual Tune & A/B

## 新增：按段落人工微调
每个段落可单独调整：
- 吉他：-50% ～ +50%
- Bass：-50% ～ +50%
- 鼓：-50% ～ +50%
- 键盘：-50% ～ +50%
- Fill：-50% ～ +50%
- 留白：-50% ～ +50%

0 表示继续使用 NOVRIA 的自动音乐性策略。

## A / B 两套编配
可以保存：
- 版本 A
- 版本 B

例如：
A：副歌吉他 +20%，鼓 +10%，Fill +25%
B：副歌键盘 +15%，吉他 -10%，留白 +10%

然后分别生成 A / B MIDI，继续用 SoundFont 渲染为 WAV/MP3 试听。

## 为什么这样设计
自动编配负责完成 80% 的工作，
最后 20% 的音乐审美交给用户快速调整，而不是逼用户进入复杂 DAW 修改每一个 MIDI 音符。
