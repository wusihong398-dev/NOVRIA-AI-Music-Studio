# NOVRIA AI Music Studio v1.5.0 — A/B Live Compare & History

## A/B 一键渲染
版本 A、版本 B 可以分别生成 WAV，用于真实音色对比。

## A/B 试听
- 试听 A
- 试听 B
- 停止试听
- 可只循环当前段落

例如只循环副歌，连续比较 A/B 两种编配，不需要每次从歌曲开头听。

## 采用正式版本
- 采用 A
- 采用 B

采用后，该版本成为当前正式编配，并自动保存历史快照。

## Undo / Redo
保存版本和采用版本前会记录状态，可撤销/重做。

## 编配历史
支持手动“保存历史快照”，记录：
- 时间
- 当前采用版本
- 人工微调
- A/B 配置
- 文件路径

## 推荐工作流
AI 音乐性编配
→ 人工微调
→ 保存 A / B
→ 生成 A / B MIDI
→ 渲染 A / B WAV
→ 只循环副歌/主歌试听
→ 采用 A 或 B
→ 继续进入正式 WAV/MP3 导出。
