# NOVRIA AI Music Studio v0.6.0 Live Pro

## 新增
- Setlist 演出歌单
- 歌曲上移/下移/删除/载入
- 自动下一首开关
- 现场演出 Pro 页面
- 演出锁定，降低误触风险
- 紧急停止按钮
- 主输出 / 耳返设备选择
- 耳返节拍器入口
- 4拍 Count-in
- USB/MIDI 脚踏板扫描
- 升降调参数入口（-12~+12半音）
- 速度参数入口（0.50x~1.50x）
- 工程保存 Setlist / 调性 / 速度参数
