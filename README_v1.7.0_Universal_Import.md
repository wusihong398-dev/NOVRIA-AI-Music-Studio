# NOVRIA AI Music Studio v1.7.0 — Universal Import

## 多格式本地导入
支持：
MP3 / WAV / FLAC / M4A / AAC / OGG / Opus / WMA / AIFF / AIF / ALAC / AC3 / APE / MKA / CAF

## 批量导入
- 多选文件
- 整个文件夹递归导入
- 导入队列
- 自动显示格式、大小、状态

## 工作格式统一
原始文件保留在 originals。
工作音频统一通过 FFmpeg 转为：
- WAV
- 44.1 kHz
- Stereo
- PCM 24-bit

后续六轨、BPM、调性、和弦、改编都优先使用工作 WAV。

## 去重
可开启 SHA-256 指纹去重。
相同文件再次导入时可直接复用已经生成的工作文件。

## 分享链接
支持：
- 粘贴 URL
- 粘贴整段分享文字自动提取 URL
- 从剪贴板粘贴
- 可选监听剪贴板
- 明确的公开音频直链可下载后加入导入队列

## 平台保护
NOVRIA 不绕过：
- DRM
- 会员限制
- 付费下载
- 登录验证
- 平台访问控制

如果第三方音乐软件提供公开下载接口、用户自己的可下载文件 URL 或官方授权 API，
后续可为该平台增加专用导入适配器。
