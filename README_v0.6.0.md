# NOVRIA AI Music Studio v0.6.0 Performance

本版本重点把现场控制从“界面入口”升级成实际运行能力。

## v0.6.0 已实现
- Setlist 播放结束自动切换下一首
- 若下一首已有六轨缓存，自动加载并继续播放
- MIDI / USB 脚踏板实际监听与控制
  - Note/CC 36：播放 / 暂停
  - Note/CC 37：停止
  - Note/CC 38：下一首
  - Note/CC 39：上一首
- 独立耳返节拍器
  - 可选择耳返输出声卡
  - Click 不进入主扩播放器
  - BPM 优先使用歌曲分析结果
- 现场会话每 5 秒自动保存
- 启动后恢复 Setlist、当前歌曲序号、升降调和速度参数
- 保留演出锁定、紧急停止、4拍 Count-in、六轨 Mute/Solo、波形、Marker、BPM/调性分析

## 仍在下一阶段实现
- 主扩 Stem 混音 + 耳返 Stem 混音完全独立的双总线
- 高质量实时升降调不变速
- 高质量实时变速不变调
- 每首歌单独保存演出预设
- MIDI 自定义映射界面

## 建议测试
1. 准备两首已经分轨的歌曲，并加入 Setlist。
2. 开启“播放结束自动下一首”，测试第一首结束后是否自动切换。
3. 插入 USB/MIDI 脚踏板，点击“扫描 MIDI”。
4. 测试 36/37/38/39 控制。
5. 选择第二个输出设备作为耳返，开启耳返节拍器，确认主扩不出现 click。
6. 关闭软件后重新打开，检查 Setlist 是否恢复。
