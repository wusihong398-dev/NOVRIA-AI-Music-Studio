# NOVRIA AI Music Studio v1.3.0 — Musical Intelligence

本版本让智能编配开始具备“段落音乐性”，而不是每个小节机械重复同一种伴奏。

## 段落角色
NOVRIA 会根据 Marker/段落名称和歌曲位置，把段落映射为：
- 前奏
- 主歌
- 副歌
- Bridge
- 间奏/独奏
- 尾奏

如果用户已经人工标记“主歌/副歌/间奏”，优先使用用户 Marker。

## 音乐性变化
### 前奏
- 乐器密度降低
- 鼓弱化
- 吉他更倾向分解
- 键盘承担更多氛围

### 主歌
- 保持空间
- Bass 稳定
- 鼓和吉他不过度抢戏

### 副歌
- 吉他增强
- Bass 运动增加
- 鼓力度增强
- 更容易安排段落 Fill

### Bridge
- 自动减配
- 吉他密度降低
- Piano/Pad 留空间
- 鼓减少存在感

### 尾奏
- 逐步收束
- Bass/Guitar/Drums 密度降低
- 键盘可使用长音铺底

## 乐器避让
当 Guitar 与 Piano 都设置高密度时，NOVRIA 会根据段落自动让其中一个简化，
避免两个和声乐器始终使用同样密度和节奏型。

## 能量曲线
- 自动判断
- 渐进增强
- 平稳现场
- 强弱对比
- 抒情克制

## 完整工作流
歌曲分析 → 乐手设置 → 段落音乐性策略 → 智能编配 MIDI → SoundFont 渲染 WAV/MP3。

这仍然是算法编配系统，不等于人工编曲师的最终音乐审美判断。生成后仍建议试听并允许用户人工调整。
