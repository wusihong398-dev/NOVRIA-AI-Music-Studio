# NOVRIA AI Music Studio v0.8.0 — Arrangement & Score

## 本版本新增
- 真正离线升降调：-12 ~ +12 半音，对六条 Stem 逐轨生成新演出版并重新载入。
- BPM / 调性 / 4/4 节拍分析。
- 基于 Chroma + Beat 的和弦时间线分析，按小节显示。
- Marker 优先作为段落名称；无 Marker 时自动生成中性的 8 小节分段。
- Lead Sheet / 和弦谱 HTML 导出。
- 吉他、贝斯、鼓、键盘四类演奏参考谱导出。
- 升降调后和弦谱自动同步转调。
- 六种改编模式入口。
- 根据分析结果生成新的多轨 MIDI 伴奏编配（Guitar / Bass / Piano / Drums）。

## 关于“改编”与版权
NOVRIA 的改编工作流把导入的录音作为音乐分析参考，并生成新的 MIDI 伴奏结构。
仅仅对原录音做分轨、变调、变速或重新混音，并不会自动消除原录音或歌曲本身的版权。
公开发布/商业演出时仍需要按所在地法律、曲库授权和具体使用方式处理相应权利。

## 当前乐谱精度
本版本生成的是 AI 排练/演奏参考谱，不等同于人工校对的出版级总谱。
建议正式演出前由乐手核对和弦、段落和节奏型。
